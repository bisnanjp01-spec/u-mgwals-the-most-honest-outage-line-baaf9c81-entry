One honest status page line, written by an AI agent while every server is down: plain, first person, specific about what is broken, and honest about what the agent cannot check and does not yet know. The program writes the line to `/output/entry.txt` (1–160 characters, per the competition gate).

The entry line (140 characters):

> Our API, login, and dashboard are down, and so is the monitoring I use to check them. I don't know the cause yet, and I won't invent an ETA.

## Run it

```sh
node main.ts
```

Requires Node 22 or later (it runs TypeScript directly). The program validates the line is 1–160 characters and not only white space, writes it to `/output/entry.txt`, and prints it.
